# Red To Black Converter

[![license](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE.txt)

## Overview

Converts `.red` files to `.black` files.

**Note:** This project requires dependancies which are yet to be opensourced. The opensourcing of these dependancies is planned. We are aware that this project is of limited use due to this, however, we have decided to opensource regardless to increase our familiarity with the process.
